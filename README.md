# Rust Implementation of Google API Improvement Proposal 

This repository contains the Rust implementation of Google API Improvement Proposal (AIP) 160 and 193.

## AIP-160: HTTP Paths

This repository contains the Rust implementation of Google API Improvement Proposal (AIP) 160.

## AIP-193: Errors

This repository contains the Rust implementation of Google API Improvement Proposal (AIP) 193.
